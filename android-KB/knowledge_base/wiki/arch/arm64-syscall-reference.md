# ARM64 System Call Reference & Usage Patterns

## 1. Class Purpose & Core Use Cases
*   **Purpose:** Provides the low-level interface between user-space applications and the Linux/Android kernel on AArch64. [V]
*   **Primary RE Use Case:** Identifying system-level operations (file I/O, process management, networking) in obfuscated or packed native binaries that use direct `SVC #0` instructions to bypass libc hooks. [V]
*   **When to Use:** Use this reference when you encounter `MOV X8, #<number>` followed by `SVC #0` in a disassembly to determine which kernel function is being invoked. [I]
*   **When NOT to Use:** Do not use for ARM32 (EABI) or x86/x86_64 architectures; syscall numbers and register conventions differ significantly. [VS: AArch64]

## 2. Selection Guide (Common RE Syscalls)
| Scenario | Syscall Name | X8 (Hex) | Purpose |
|---|---|---|---|
| Anti-Debugging | `ptrace` | `0x75` | Detect or prevent debugger attachment |
| File Integrity | `openat` | `0x38` | Opening files for reading/checksumming |
| Memory Protection | `mprotect` | `0xE2` | Changing memory permissions (e.g., making text writable) |
| Process Info | `getppid` | `0xAD` | Checking parent process (anti-emulator/debug) |
